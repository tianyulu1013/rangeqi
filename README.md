# 阵衡

一款“棋子不能移动”的静态布阵棋。双方轮流放置棋子，全部放完后，根据攻击与支援关系进行连锁清算。

## 核心规则

- 每方拥有斥候 3、卫士 3、射手 1、炮台 1、骑士 1、堡垒 1，共 10 枚棋子。
- 炮台沿上下左右寻找炮架；越过第一枚棋子后开始控制格子，遇到下一枚棋子后停止。
- 棋子放置后不能移动；攻击范围同时也是支援范围。
- 危险值 = 被攻击次数 − 受支援次数。
- 清算时，每轮同时移除全场危险值最高且大于 0 的棋子，然后重新计算。
- 清算结束后，存活棋子更多的一方获胜。
- 存活棋子数相同，则比较控制格数；仍相同才是平局。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 纯静态构建

```bash
npm run build:static
```

构建产物会生成到 `docs/`，并同步一份到仓库根目录供 GitHub Pages 使用。不需要服务器、数据库或 API，AI 的全部决策逻辑都在浏览器本地运行。

GitHub Pages 使用 `main` 分支根目录发布；推送后即可更新游戏。
